# Zomato Insights Dashboard

An interactive Power BI dashboard for exploring Zomato order and restaurant data. Built using the Zomato dataset in Excel, the report brings key metrics and breakdowns together to make patterns in customer ratings, delivery times, order amounts, and restaurant performance easier to explore.

## Dashboard highlights

- Summary cards for total orders, customer satisfaction, average delivery time, and order amount
- Interactive filters for restaurant type, restaurant location, rating, and order date
- Visual breakdowns that let users compare results across categories and time periods
- A second report page featuring Zomato themed imagery

## Tools and files

- **Power BI Desktop** — report and dashboard
- **Microsoft Excel** — source dataset
- `zomato_project_PBI.pbix` — Power BI project file
- `Zomato.xlsx` — source data

Open the `.pbix` file in Power BI Desktop to explore the report and interact with its filters.
